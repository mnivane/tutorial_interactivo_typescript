# 🚀 TypeScript: Guía Práctica de Fundamentos y POO

Este repositorio contiene la resolución de los **40 retos prácticos** propuestos en la *Guía del Estudiante: Tutorial TypeScript Paso a Paso*. 

El proyecto está diseñado para aprender y consolidar las bases del lenguaje mediante ejercicios del mundo real, ejecutados de manera rápida en la terminal utilizando el entorno de **Bun**.

---

## 📋 Estructura de los Retos

Los ejercicios están organizados según los bloques principales de la guía:

1. **Métodos Avanzados de Arrays:** Prácticas intensivas de transformación, filtrado, búsquedas y acumulación de datos utilizando `map`, `forEach`, `reduce`, `some`, `every`, `find` y `sort`.
2. **Estructuras de Datos y Tipado:** Creación y manipulación de tipos personalizados (`type`), contratos (`interface`) y el uso de propiedades de solo lectura (`readonly`).
3. **Programación Orientada a Objetos (POO):** Modelado de sistemas reales mediante el uso de clases, métodos, encapsulamiento estricto de propiedades (`private` / `public`), y validación de datos a través de `getters` y `setters`.
4. **Abstracción y Polimorfismo:** Implementación de interfaces para contratos de software múltiples y jerarquías complejas utilizando clases abstractas.
5. **Tipos Genéricos (`<T>`):** Construcción de estructuras de datos y repositorios reutilizables y escalables con restricciones de tipo (`extends`).

---

## 💻 Cómo Ejecutar los Archivos

Para correr cualquiera de los retos directamente en la terminal con **Bun**, usa el siguiente comando:

```bash
bun run nombre_del_archivo.ts
